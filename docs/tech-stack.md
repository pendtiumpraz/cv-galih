# Tech Stack

## Frontend

| Teknologi | Kegunaan |
|-----------|----------|
| **HTML5** | Struktur halaman |
| **Tailwind CSS** (CDN) | Utility-first styling |
| **JavaScript** (vanilla) | Interaktivitas, animasi, ekspor PDF |
| **Google Fonts** | Inter & JetBrains Mono |

## Libraries (CDN)

| Library | Fungsi |
|---------|--------|
| `html2pdf.js` | Ekspor halaman ke PDF di sisi klien |

## Tools

| Tool | Kegunaan |
|------|----------|
| **CDN Tailwind** | Styling tanpa build step |
| **Google Fonts** | Tipografi kustom |

## Catatan

Proyek ini tidak menggunakan:
- Framework JavaScript (React, Vue, dll)
- Build tools (Webpack, Vite, dll)
- Package manager (npm, yarn)
- Backend atau database

Semua murni **static HTML + CSS + JS** via CDN.
