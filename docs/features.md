# Features

## CV Digital Interaktif

- Halaman HTML tunggal dengan desain modern dark-theme
- Animasi latar belakang gradien dinamis
- Navigasi smooth scroll antar bagian
- Grid portofolio dengan kartu proyek

## Ekspor PDF

- Tombol "Download CV" untuk ekspor ke PDF
- Menggunakan library `html2pdf.js` di sisi klien
- Versi cetak terpisah (`cv-print.html`) untuk tampilan optimal

## Informasi Profesional

- **Header:** Nama, gelar, tautan (LinkedIn, GitHub, portfolio Vercel)
- **Ringkasan:** Profil profesional AI Engineer
- **Proyek:** Grid portofolio 20+ proyek AI dan web
- **Pengalaman:** Timeline pengalaman kerja
- **Pendidikan:** Latar belakang pendidikan
- **Sertifikasi:** Sertifikat dan pelatihan

## Portofolio Terintegrasi

- 20+ proyek ditampilkan di halaman CV
- Tautan langsung ke demo (Vercel) dan repositori (GitHub)
- Proyek mencakup AI Chatbot, RAG systems, platform edukasi

## Kontak & Media Sosial

- LinkedIn
- GitHub
- Portfolio Vercel
- Email
