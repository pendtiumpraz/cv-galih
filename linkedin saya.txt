Project Overview

A high-performance Web RPA platform for Opsguide.cloud, designed to automate mass outreach in the Japanese market by submitting contact forms instead of sending emails. This strategic shift in outreach has proven highly effective, with the platform successfully onboarding 150 Japanese partner companies since its launch in July 2025.

My Role & Key Contributions: AI Engineer

As a core engineer, I architected and implemented critical features across the full stack.
- Core Automation Engine: I built the primary automation engine using Playwright, which included a robust URL checker, dynamic scenario creation logic, and advanced error handling. I also developed a scenario validation system to ensure a high success rate and designed the status tracking flow.
- Scalable AWS Infrastructure: I engineered the backend infrastructure, configuring AWS Batch for large-scale parallel RPA tasks and setting up a broad /19 public IP range to prevent blocking. I also built the pipeline to automatically capture Playwright screenshots and video recordings, storing them in S3 for easy access and debugging on the frontend.
- Monitoring & Data Management: I created essential monitoring dashboards for tracking scenario generation and built the CSV upload/download feature for partners to manage their campaigns and review results.
- Automated Target Discovery: Currently, I am developing a sophisticated web crawler to automatically discover and extract company URLs from directory websites, feeding them directly into our automation pipeline for scenario generation and execution.

Technology Stack
- AI Engine: DeepSeek
- Automation: Playwright
- Frontend: React (TypeScript)
- Backend: Python (FastAPI)
- API: GraphQL
- Database: PostgreSQL
- Cloud & Infrastructure: AWS (Batch, S3, Lambda, IP Management)
- Monitoring: Grafana
